# 模板固化上下文与能力，而非目录快照

Workspore 的口号是「不再从零搭脚手架」，但模板本身不含任何目录结构。我们决定：模板 = 固化的上下文 + 能力。目录、命名、流转这些约定写在指令文件里，是写给 agent 看的声明；新实例落地时 agent 读上下文、自己长出结构，而不是从模板里搬运空骨架。

**Considered Options**: 目录快照式模板（携带初始目录骨架，实例还原时展开）——被否：空目录既无内容也无必要，结构由声明驱动、agent 按需物化。这是与传统脚手架工具（cookiecutter / copier 一类）的本质分界：搬的不是目录，是让 agent 自己长出目录的东西。
